# Go-reloaded#

Un outil en ligne de commande écrit en **Go** qui complète, édite et autocorrige un texte selon une série de règles définies.

---

## Description

`Go-Reloaded` prend un fichier texte en entrée, applique plusieurs transformations (conversion de nombres, modification de casse, correction de ponctuation, etc.) et écrit le résultat dans un fichier de sortie.

---

## Objectifs

- Réutiliser des fonctions déjà écrites dans un ancien dépôt.
- Créer un outil simple de complétion, d'édition et d'autocorrection de texte.
- Écrire ses propres tests unitaires.

---

## Utilisation

```bash
go run . <fichier_entrée> <fichier_sortie>
